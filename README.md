# Yield Finder

## Project Overview
Yield Finder is a Python desktop application that analyzes a parse tree and returns its terminal yield by traversing the leaves from left to right.

## Problem Statement
Build an analyzer that takes a completely formed parse tree structure and returns its terminal yield string through left-to-right traversal.

## Features
- User can enter a custom parse tree.
- Generates the terminal yield from left to right.
- Validates parse tree input.
- Displays valid and invalid input messages.
- Shows step-by-step analysis.
- Visualizes the parse tree.
- Provides an example input.
- Exports the result to a text file.
- Includes screenshots for testing.

## Technology Used
- Python 3
- Tkinter GUI
- Python built-in libraries
